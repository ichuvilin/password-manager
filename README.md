# 🔐 Password Manager: Цифровой сейф в мире киберпанка

Консольный менеджер паролей на Go для безопасного хранения, генерации и управления паролями.

Приложение предоставляет CLI-интерфейс для работы с паролями и сохраняет данные в локальном зашифрованном файле.

![Go](https://img.shields.io/badge/Go-1.27-00ADD8?logo=go)
![License](https://img.shields.io/badge/license-MIT-green)

---

## 📋 Возможности

Password Manager позволяет:

* 🔑 устанавливать master password;
* 🔐 хранить пароли в локальном зашифрованном хранилище;
* 🎲 генерировать случайные пароли;
* ➕ добавлять новые пароли;
* 🔎 искать пароль по названию сервиса;
* 📋 просматривать список сохранённых паролей;
* ✏️ изменять существующие пароли;
* 🗑️ удалять пароли;
* 🗂️ группировать пароли по категориям;
* 📊 просматривать статистику хранилища;
* 🔍 находить повторно используемые пароли;
* 💾 автоматически сохранять изменения при выходе.

### Шифрование

Для защиты данных используется:

* AES-256;
* AES-GCM для шифрования и проверки целостности;
* криптографически безопасный генератор случайных данных `crypto/rand`;
* уникальный nonce для каждого сохранения файла.

Хранилище сохраняется в локальный файл:

```text
ps.dat
```

Файл с данными добавлен в `.gitignore` и не должен попадать в репозиторий.

> **Важно:** проект является учебным CLI-приложением. Несмотря на использование криптографических примитивов, его не следует использовать для хранения реальных критически важных паролей без дополнительного аудита безопасности.

## 🛠️ Использование

После запуска приложение запрашивает master password:

```text
Enter master key:
```

Master password должен содержать минимум 8 символов.

После успешной инициализации открывается главное меню.

### Генерация пароля

Выберите:

```text
1. Generate new password
```

Затем укажите длину пароля.

Минимальная длина — 8 символов.

Генератор использует:

* строчные буквы;
* заглавные буквы;
* цифры;
* специальные символы.

### Добавление пароля

Выберите:

```text
2. Add new password
```

Укажите:

1. название сервиса;
2. пароль;
3. категорию.

Если оставить поле пароля пустым, приложение автоматически сгенерирует новый пароль.

### Получение пароля

Выберите:

```text
3. Get password
```

После ввода названия сервиса приложение покажет сохранённые данные.

### Список паролей

Выберите:

```text
4. List all passwords
```

Приложение отобразит список сохранённых записей:

```text
=== Password list ===
Name                 Category        Created              Last Modified
--------------------------------------------------------------------------------
GitHub               Development     2026-09-23           2026-09-23
Google               Personal        2026-09-23           2026-09-23
```

### Обновление пароля

Выберите:

```text
5. Update password
```

Введите название сервиса и новый пароль.

Новый пароль проходит проверку сложности.

### Удаление пароля

Выберите:

```text
6. Delete password
```

После этого укажите название записи.

### Категории

Выберите:

```text
7. List categories
```

Приложение выведет список используемых категорий.

### Статистика

Выберите:

```text
8. Show password statistics
```

Статистика содержит:

* общее количество паролей;
* количество записей в каждой категории;
* дату самой старой записи;
* дату самой новой записи.

### Поиск повторяющихся паролей

Выберите:

```text
9. Find duplicate passwords
```

Приложение определяет пароли, которые используются несколькими сервисами.

### Выход

Выберите:

```text
0. Exit
```

Перед завершением работы данные сохраняются в зашифрованный файл `ps.dat`.

## 🔒 Безопасность

Проект использует AES-256-GCM для шифрования локального хранилища.

При сохранении:

```text
Password data
      ↓
    JSON
      ↓
  AES-256-GCM
      ↓
Encrypted data
      ↓
    ps.dat
```

При загрузке выполняется обратная операция:

```text
ps.dat
  ↓
Encrypted data
  ↓
AES-256-GCM
  ↓
JSON
  ↓
Password data
```

Master password не сохраняется в файл.

Файл `ps.dat` должен храниться только локально и не должен добавляться в Git.
